## 版本管理

`main` 保存经过检查的可用基线；后续功能使用独立分支，经检查后合并。仓库记录源码、锁文件、现行文档、历史研究和可直接试玩的原型快照；依赖与运行缓存由本地重建。`outputs` 与 `work` 只跟踪目录占位文件。仓库为公开可见，不放托管配置或凭据。

原目录保留为迁移备份，后续以此目录为唯一开发入口。首次提交使用项目迁移时的现状，不将历史效果稿虚构为逐次 Git 提交。
