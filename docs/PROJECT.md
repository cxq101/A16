## 项目定位与范围

以不同状态的卡牌及碎片为整理对象，通过收集、翻面、去污、拼接和归档，将混乱逐步恢复为秩序。拼接是整理手段，收藏集记录成果，美术增强完成反馈；不以追求新卡作为唯一动力。

当前版本面向 Steam Windows PC、键盘＋鼠标、简体中文。完整流程与十二卡验证版的已确认配置统一见 [玩法与内容](GAMEPLAY.md#gameplay)，不在本文件复制规则表。联机、交易经营、对战与移动端发行尚未纳入批准范围。

用户已认可继续整理的动力、三维倾斜桌面与当前 Godot 效果验证。主要风险仍是美术品质、生产成本及持续操作节奏；玩法反馈不等于市场销量验证。正式名称、世界观和正式卡表、发行内容规模、最终画风、预算与排期尚未确定。

## 当前实现与待扩展

Godot 已替代旧演示，当前唯一开发工程是 godot。运行与版本见 [技术文档](TECHNICAL.md#technical)，用户试玩及自动检查的历史证据见 [记录](RECORDS.md#godot-validation)。

- 三张卡为听潮幼鲸、逐月灵鲸、月潮之鲸，使用 Godot 工程内保留的待审阅稿，分别覆盖干净整卡、脏整卡和六片碎片；共 8 个初始对象。卡名与素材尚不是最终量产批准。
- 已实现第一人称移动、拾取入容器、整批倒出、桌面堆积掉落、正反面翻转、单对象局部擦拭、六片凹凸拼接、目标切换、三页简化收卡设备、错误返回、单卡快捷归位、归档反馈、主动欣赏、位置提示、暂停和独立存档。
- 场景为程序化样板环境，使用三张效果稿；不是最终美术。收卡设备为每页一个有效归档目标的三页验证，九格外观只是示意，不表示完成正式目录与全部九格交互。
- 当前只有三卡，因此只验证归档 2 张时容量 12→18；归档 4／6 张的清理提效与批量拾取尚未实现。十二卡、四状态各三张的完整随机配比尚未接入；三卡使用固定状态组合、随机位置与正反面。

### 尚待完成

当前为三卡 Godot 流程样板。十二卡状态配比、归档 4／6 张的能力、正式收卡目录和每页完整槽位仍待扩展。完整验证版的拿取或归档中断恢复、正式性能和发行验收尚未完成；已替换旧运行代码不等于这些目标全部达成。

现有审阅图尚非最终生产美术；具体制作标准与审批状态见 [美术文档](ART.md#art) 与 [资产登记](../.project/artifacts.json)。
