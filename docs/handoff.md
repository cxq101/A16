## 接手检查清单

1. 确认工作目录和治理版本；检查是否已有用户新决定覆盖文档。
2. 查看原型源码与生成关系，运行时保护用户已有存档。
3. 先核对待审阅图和现行卡牌规则，不能从旧图恢复属性、系列正面或编号分母。
4. Git 初始基线已建立；如果开始正式引擎开发，先落实引擎与核心库边界，不擅自采用 Unity／BaX。
5. 每次交付记录实际检查、剩余限制，并同步对应权威文档。

## 现有材料能支撑与不能支撑的判断

能支撑：玩法曾被用户认可，三维桌面方向值得保留，卡牌信息已较明确，已有多轮可比较的效果稿。

不能支撑：已经找到最终画风、已经确定独立开发总成本、没有直接竞品、生产引擎已定、收卡机器已实现、正式版经济已平衡或最新生成图已通过用户验收。
