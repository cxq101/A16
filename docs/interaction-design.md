# 桌面与收藏交互

## 已验证桌面方向

用户确认三维视角提升体验，倾斜视角未影响辨认和归位。采用固定倾斜桌面是当前方向，正式镜头参数尚未锁定。

现有三维样板支持拾取拖放、吸附归位、缩放、平移、卡牌完成展示、翻面和收入收藏展示。应保留「拿起 → 移动 → 接近目标 → 落位 → 完成」的连贯反馈。触控点击是二维原型的适配能力，不代表已经决定移动端发行。

## 《再拆亿包》的收卡设备：已知边界

用户重点希望参考能翻页、快速放置的收藏设备。官方截图可见实体双页卡册，每页 3×3 插槽，翻页标识、滑动控件、按钮和页码显示。官方介绍还提到自动收卡设备 BinderBot。这些是参考观察，不是本项目已经实现的功能。

本对话未安装试玩其 Demo；不能据此确定原版的全部按键、吸附阈值、翻页时机与快速收卡算法。网上 Shift＋Click 自动翻页归位的资料来自 MOD，不能当作原版默认交互。截图中 `1/20` 等指示的含义也未经确认。来源见 [参考资料](references.md)。

## 本项目的交互提案

完成卡牌后进入独立的收卡阶段，卡册提供有固定身份的收藏槽。允许手动翻页，同时提供快速定位缺口或目标页的途径；快速放置需看得清卡片最终去了哪里，避免只看到数字增加。

建议验证以下最小交互：当前页拖放、翻页控件、快速跳至目标页、可选的快速归位方式，以及翻错页／重复卡／未解锁页的反馈。每页九格、左右页布局、快捷键、自动翻页和动画时长均是待验证选项，不直接照搬竞品。

快速归位服务于**已拼好的卡**，不默认自动完成拼图。卡面编号与收藏槽之间要建立可靠映射，但全局编号还是系列内编号尚未决策。

## 建议验证场景

用三页收藏槽和少量已完成卡测试：同页连续入册、跨页入册、最后一个缺口、返回前页、重复卡和快速操作中途取消。记录翻页次数、寻找目标耗时、错误放置、是否需要回看，以及玩家能否说出卡放到了哪里。

对比手动拖入、自动定位后手动放入、一键归位三种参与程度，避免先引入升级冷却再判断基础操作是否好用。具体测试阈值与最终实现方案尚未批准。

## 当前缺口

现有三维原型只有两张卡的收藏展示与图鉴，没有多页收卡机器、目标页快速跳转或连续大批收卡。下一次开发不应把「已有入册动画」误认为「已实现竞品收卡体验」。
