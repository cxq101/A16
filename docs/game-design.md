# 玩法与成长设计

## 核心循环

领取或取出一组待整理碎片 → 在托盘辨认所属卡牌及位置 → 拼接正确归位 → 展示完整卡牌与材质 → 归入系列收藏 → 查看缺口并继续下一张。

「获取碎片」的最终包装尚未确定，不默认采用随机抽包。拼接与收藏是当前项目的核心；清洁、买卖、经营、自动拆包等是其他游戏的做法。

## 原型现状

| 环节 | 当前实际实现 | 正式版状态 |
| --- | --- | --- |
| 拆分 | 每卡 2×3 六块矩形，不旋转 | 数量、形状与旋转规则待定 |
| 低混合 | 同系列两张卡，共 12 片 | 有效的入门测试方式，数值未锁定 |
| 高混合 | 同系列六张卡，共 36 片 | 有效的进阶测试方式，正式难度待定 |
| 放置 | 点击选择后点击位置，或拖放；错误归位拒绝 | 需继续保留清楚反馈，具体容错待验证 |
| 辅助 | 原图、位置提示、重新打散、音效开关 | 正式版辅助配置和提示成本待定 |
| 成长 | 完成两张解锁可切换的同卡碎片高亮 | 已实现的验证机制，非最终成长曲线 |
| 收藏目标 | 每系列六张完成后解锁展示页 | 已实现，正式系列规模待定 |
| 三维样板 | 两张卡、十二片，完成后查看、翻面、入册 | 未与二维十二卡内容和成长统一 |

两种混合程度改变的是**同时混入的卡牌数量**，不是一张卡内部的拆分数，也不是强制引入第二套小游戏。原型低、高混合共享收藏进度，且不跨系列混合。

同卡高亮只标出当前卡剩余碎片，不自动拼接，不直接提供目标位置。原图与位置提示是独立的辅助功能。

## 成长机制建议（尚未定案）

以收藏进度解锁新系列和展示变化，再逐步增加混合程度。让玩家获得更高效的整理工具，同时保留辨认、取放和完成卡牌的反馈。工具升级可减少重复劳动，但不宜直接完成全部核心操作。

先验证「收藏缺口是否令人想补齐」，再引入货币、抽卡概率、重复卡转化或自动化。若使用随机获取，需要专门设计后期缺卡的可达成路径；不能把漫长等待和纯概率补洞当作内容。

## 需要避开的设计风险

- 卡面构图过于相似或背景大面积空白，导致碎片难以识别、只能试错。
- 难度仅靠堆积碎片和遮挡，增加翻找负担，却没有新的判断乐趣。
- 自动拼接或过强提示消耗全部参与感；相反，强制反复翻册也会拖慢收藏节奏。
- 稀有度仅改变文字，收集奖励缺少视觉价值；也不能让金光掩盖主角。
- 把二维原型的解锁数值直接当成经过验证的商业版本成长曲线。

最终难度、获取方式、经济、重复卡处理、失败规则、单局时长均是待决事项。卡牌字段与品质的具体约束见 [卡牌规范](card-spec.md)。
