# 碎光收藏室

> 历史原型说明（2026-11-24 归档提示）：本文保留实现和历史试玩记录，不是正式产品规范。当前入口见 [项目 README](../README.md)，现行字段见 [卡牌规范](../docs/card-spec.md)，实际实现边界见 [技术基线](../docs/technical-baseline.md)。下文旧美术与旧数值不表示正式验收通过。

浏览器卡牌拼接原型第二版：12 张原创矢量卡面，每张拆成 2×3 共 6 片，共 72 片。两个系列分别是深色奇幻风格的「星旅藏集」和暖色复古风格的「时光工坊」。本轮只在本地开发，没有上传或发布。

双击打开 `demo.html` 即可离线游玩，无需安装依赖。它是包含全部样式、图案和逻辑的独立文件。也可以直接打开 `dist/index.html`。

修改 `dist/` 源码后运行 `node build.cjs` 重新生成独立文件。需要本地 HTTP 服务时运行 `node serve.cjs`，访问 http://127.0.0.1:5173 。

- 低混合：每组两张卡，每个系列三组；高混合：当前系列六张卡同时出现，两个系列不会混进同一托盘。
- 两种模式共享收藏进度；左侧切换系列、卡片或低混合分组。
- 支持拖放或点击碎片后点击目标空位，移动设备可用点击操作。
- 查看原图、位置提示、重新打散、音效开关、本地自动存档。
- 完成任意两张卡后解锁「同卡碎片高亮」，可手动开关。开启后为当前卡的剩余碎片描边，切换卡片时自动更新；不会自动拼接，也不提示目标位置。
- 每个系列集齐六张卡后解锁专属展示页，可随时再次查看，并从奖励页开始/继续另一个系列。
- 使用 v2 存档；首次打开时会读取同一浏览器、同一地址下的 v1 存档，保留原六张卡的已完成和部分拼接进度。新增系列初始为空，升级根据已有完成数解锁。原 v1 存档不改写。

本版重点验证混合识别、拼接与收藏反馈，使用矩形六宫格碎片；尚未实现第一人称场景、清洁、交易、稀有度概率或经济成长。藏品稀有度为展示设定。存档仅属于当前浏览器与站点；更换浏览器/地址不共享。

已通过真实浏览器检查：v1 完成与部分进度迁移、低混合 12 片与高混合 36 片、系列隔离、拖放和错误放置、原图与提示、完成两张时解锁高亮、高亮切换与存档、全部十二张完成、两套展示奖励和前往下一套、刷新恢复，以及 390px 手机布局。`qa.cjs` 是本次 Playwright CLI 试玩脚本，仅操作测试 HTTP 地址的存档，不操作用户 file:// 地址的存档。

建议试玩时关注：第一套完成后是否想开始第二套、同卡高亮是否减少烦躁又保留辨认乐趣、系列展示是否足以成为完成目标。

## 三维桌面材质样板

双击 `desk3d.html` 可离线体验两张卡的真实三维桌面，包括拖放、阴影、涂层、翻面和入册。“平面基准”提供同场景俯视比较，右上角可回到原版。存档独立，未上传或发布。制作范围、试玩方法和人力预算见 `3D-STUDY.md`。

源码位于 `dist/desk3d/`。安装锁定依赖后执行 `node build-3d.cjs`，生成独立文件。开发服务地址为 http://127.0.0.1:5173/desk3d/index.html 。`qa-3d.cjs` 与 `qa-3d-offline.cjs` 为 Playwright CLI 检查脚本。

2026-11-23 第二轮已将 `desk3d.html` 更新为美术样板：精修两张矢量卡面、统一星图边框与背纹、圆角纸边和金属印边、木材/织物/皮革细节、收藏插袋、声音和动画节奏。增加“藏品图鉴”和“上一版对照”。上一轮完整快照保存在 `desk3d-study.html`，本轮使用独立存档 `fragment-desk3d-art-v1`。详细规格、复用清单和成本假设见 `ART-DIRECTION.md`；`3D-STUDY.md` 保留上一轮的验证记录。

`art-assets.cjs` 生成 `dist/desk3d/assets/` 的两张 SVG 母版；`build-3d.cjs` 会调用它。`qa-art-sample.cjs` 检查图鉴、配色、预热后帧率、720p 布局和上一版快照。独立文件可通过开发服务的 `/desk3d-standalone.html` 单独验证资源内嵌。
